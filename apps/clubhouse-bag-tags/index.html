How to use Clubhouse Bag Tags

  1. Upload roster. Drop a CSV with each person’s name and assignment, or add people by hand. Need a starting point? Use Download CSV template.
  2. Check the columns. The app matches columns like Name, Player Name, First Name / Last Name and Assignment / Affiliate / Team. If it can’t, pick them yourself.
  3. Review. Rows marked Needs assignment didn’t match a destination (for example “A” or a blank). Choose the right one; nothing is guessed. Edit names, set copies, and untick anyone you don’t need.
  4. Print. Choose Letter sheets (6 per page) or Individual tags (4 × 3 in pages), then Print or Download PDF.

Printing

  • Always print at Actual size / 100%. Never use Fit to page.
  • Letter sheets: cut along the cut lines and the marks in the margins. Each tag is exactly 4 × 3 in.
  • For one tag, click its row, then Print this tag.

Destinations & logos

  • The clubs’ official logos are built in. FCL and Rehab use the Houston Astros logo. To use a different file, choose Replace logo; it stays on this computer, and Use official logo switches back.
  • You can change an address (for example an equipment-receiving address). Changes stay on this computer; Reset restores the default.
  • Each club’s ballpark photo is built in and appears behind its tags. FCL and Rehab use the Other destinations’ photo once one is uploaded, or a navy ballpark drawing until then.

Privacy

  • Rosters never leave your browser. Nothing is uploaded or saved, and the list is cleared when you close the tab.
