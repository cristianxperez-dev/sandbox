VIDEOS

Videos never upload anywhere. Game setup (text, points, order, settings) is saved automatically. Video files are too large for normal page storage, so they’re kept in the browser’s private database instead. If the browser’s site data is cleared, storage fills up, or you open this file on another computer or browser, each play will show which clip to re-select.
